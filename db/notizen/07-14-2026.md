# Notizen Tag 7

## Datenerfassung mit INSERT und VALUES Klausel

- Geben Sie immer die Spaltenliste an.
- Wenn die Anzahl Werte nicht mit der Anzahl Spalten übereinstimmt: Abbruch mit Fehlermeldung
- Sie dürfen Spalten weglassen, die optional sind oder einen Default Wert haben.
- Sie müssen Spalten weglassen, die die IDENTITY Eigenschaft haben.
- Die zu erfassenden Werte müssen zum Datentyp der Spalte passen.
- Zeichenketten, Datum und Uhrzeit in Hochkomma
- Integer und Dezimalzahlen ohne Hochkomma
- NCHAR und NVARCHAR so: N'El Niño'
- Die VALUES Klausel erlaubt mehrere Datensätze auf einmal, jeweils in runden Klammern und durch Komma getrennt.

```sql
INSERT INTO <Tabellenname> (<SpaltenName_A>, <SpaltenName_B>)
VALUES ('Hans', 5),
       ('Peter', 3);
```

## Alternativ INSERT mit SELECT-Klausel

- Die einzufügenden Werte können aus einer anderen Tabelle geholt werden

- Was tut SELECT?
  - wählt anzuzeigende **Spalten** aus
  - man nennt das **Projektion**
- Was tut WHERE?
  -wählt anzuzeigende **Zeilen** aus
  - filtert
  - das heißt **Selektion**

- Die Anzahl der Spalten in der INSERT-Liste und der SELECT-Liste muss übereinstimmen.
- Die Zuordnung erfolgt positionsbasiert (1. Spalte → 1. Spalte usw.), nicht über die Namen.
- Die Spaltennamen dürfen unterschiedlich sein, die Datentypen müssen aber kompatibel sein.

```sql
INSERT INTO Archivtabelle (<SpaltenName_A>, <SpaltenName_B>)
SELECT <SpaltenName_A>, <SpaltenName_B>
FROM TabelleX
WHERE YEAR(<SpaltenName_B>) < 2025;
```

## Datenerfassung mit Transaktionssteuerung

- Verwenden Sie Transaktionsteuerung, wenn mehrere zueinander gehöroge Änderungen an Daten erforderlich sind.
- Ziel: Einhaltung des ACID Prinzips, insbesondere A - **Atomical** bzw. *Alles oder Nichts*
- TRY ... CATCH, THROW, BEGIN TRANSACTION, COMMIT TRANSACTION, ROLLBACK TRANSACTION
- Wenn die Transaktion fehlschlägt, muss der Zustand der Datenbank vor der Transaktion wieder hergestellt sein
- Bei Tabellen mit IDENTITY-Eigenschaft wird bei Fehlern ein Wert *verbrannt*

```sql
BEGIN TRANSACTION;
BEGIN TRY
  INSERT INTO ...
  INSERT INTO ...
  COMMIT TRANSACTION;
END TRY
BEGIN CATCH
  ROLLBACK TRANSACTION;
  THROW;
END CATCH;
```
