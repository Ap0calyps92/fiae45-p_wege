Welche Attribute müssen als OPTIONAL markiert werden?

What's the meaning of an "identifying" relationship?

| Entity Type | Has Own PK? | Depends on Another Entity? | Typical Use |
| ----------- | ----------- | ----------- | ----------- |
| Regular (Strong) | Yes | No | Customer, Product, Department |
| Weak | No | Yes | Dependent, Orderitem (sometimes) |
| Associative | Usally composite PK | Depends | Enrollment, Booking, Membership |
| Supertype | Yes | No | Person, Vehicle, Account |
| Identifying Relationship | Parent PK becomes part of child PK | Used with weak entities | Employee -> Dependent |
