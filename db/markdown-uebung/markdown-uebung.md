## Wichtige Technologien für Fachinformatiker

| Technologie | Bedeutet | Aufgabe |
| -- | -- | -- |
| *HTML* | Hypertext Markup Language | Strukturiert den **Inhalt** von Webseiten |
| *CSS* | Cascading Style Sheets | Bestimmt Gestaltung und **Layout** von Webseiten |
| *JavaScript* | eigentlich ECMAScript | **Verhalten** und Usability von Webseiten |
| *AJAX* | Asynchronous JavaScript and XML | Nachladen von Inhalten in Webseiten |
| *JSON* | JavaScript Object Notation | Datenformat für Datenaustausch |
| *XML* | Extensible Markup Language | Datenformat für Datenaustausch |
| *SQL* | Structured Query Language | Sprache zum Erstellen und Abfragen von **Datenbanken** |
