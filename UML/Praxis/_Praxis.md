# UML-Praxis

Legen Sie Ihre Dateien zu den praktischen Übungen in den entsprechenden Unterordnern ab. Zu jeder Übung soll eine UXF, eine PNG und eine PDF-Datei abgelegt werden.

Binden Sie die PNG-Dateien in die zugehörigen Markdown-Dateien ein. Dort können Sie bequem Anmerkungen und Notizen zu den Übungen machen.

**Hinweis:** Beim Einbinden von Bildern bzw. beim Verlinken von Dateien nutzen Sie immer **relative** Dateipfade. Die Pfadangabe darf niemals mit einem Laufwerksbuchstaben oder einem Slash "/" beginnen. Sonst funktionieren die Verknüpfungen nicht, wenn Ihr Repository anderswo abgelegt wird.
