# Checkliste: Class Diagramm

- Achten Sie sorgfältig darauf, welche Detailtiefe die Aufgabe fordert. Manchmal sind nur Beziehungen zu identifizieren, in anderen Fällen deutlich mehr Details.

- Wenn Sie Teil-Ganzes Beziehungen erkennen, identifizieren Sie Hinweise zur Unterscheidung von Komposition und Aggregation.
  - Bei der Komposition ist das Teil existenzabhängig vom Ganzen (starker Besitz, abhängige Lebensdauer; nur das Ganze besitzt Referenzen auf seine Teile).
  - Bei der Aggregation können Teile unabhängig vom Ganzen weiter existieren bzw.nicht nur zu einem Ganzen gehören.
