# Unterrichtsmaterialien – Fachinformatiker Anwendungsentwicklung (Umschulung)

Dieses Repository enthält meine Unterlagen, Übungen und Notizen aus der Umschulung zum **Fachinformatiker für Anwendungsentwicklung**.

## 📚 Inhalte

Das Repo ist grob nach Themenbereichen sortiert:

- **Datenbanken** – ERD/ER-Modelle, SQL, Normalisierung
- **Programmierung** – OOP in Python & C#, Übungsprojekte, UML-Klassendiagramme
- **Netzwerktechnik** – IPv4/IPv6, Subnetting, Routing, VLANs, Filius/Packet Tracer
- **Digitale Prozesse** – EPK/eEPK, BPMN, Struktogramme, Flowcharts
- **Wirtschafts- und Sozialkunde / Recht** – Internetrecht, Urheberrecht, NIS-2, Markenrecht
- **Git/GitLab** – Übungen und Notizen zur Versionsverwaltung
